# きょうゆうさいとー（kyouyuusaito-）

## 概要

**「友達の意見が一番信用できる」**をコンセプトにした、仲間内で使える評価型SNSです。

インターネット上の知らない人の口コミではなく、気心の知れた友達や仲間のリアルな感想を参考にしながら、気になるもの・場所・お店を見つけられるサービスを目指しています。

## コンセプト

> 友達のおすすめなら、試してみたい。

「このお店、実際どうだった？」
「買ってよかったものは？」
「おすすめの食べ物は？」

そんな日常の会話から生まれる情報を、仲間内で共有・評価できる場所をつくります。

## できること

- 物・店・食べ物などを投稿する
- 投稿したものを仲間内で評価する
- 友達のおすすめや感想を確認する
- 自分が気に入ったものを記録・共有する
- 仲間のリアルな評価を参考にして、新しいものを見つける

※現在は開発中のため、機能や画面構成は今後変更される可能性があります。

## 想定している利用シーン

- 友達同士でおすすめの飲食店を共有したい
- 買ってよかった商品を仲間に教えたい
- 行ってみたいお店の評判を友達から聞きたい
- 自分たちだけのおすすめランキングを作りたい
- 大きな口コミサイトより、身近な人の感想を重視したい

## 大切にしていること

### 信頼できる情報

顔や関係性が見える仲間の意見だからこそ、より身近で信頼できる情報になります。

### 気軽な共有

難しいレビューではなく、「よかった」「普通だった」「また行きたい」など、気軽な感想を共有できることを目指します。

### 仲間内で楽しめること

評価を通じて会話が生まれたり、新しい発見があったりする、閉じたコミュニティならではの楽しさを大切にします。

## 開発環境

```bash
# リポジトリをクローン
git clone https://github.com/miriyuki11/kyouyuusaito-.git

# プロジェクトディレクトリへ移動
cd kyouyuusaito-

# 依存関係をインストール
npm install

# 環境変数を設定（Supabaseのプロジェクト情報を .env.local に設定）
# NEXT_PUBLIC_SUPABASE_URL=xxxx
# NEXT_PUBLIC_SUPABASE_ANON_KEY=xxxx

# 開発サーバーを起動
npm run dev
```

開発サーバー起動後、ブラウザで表示されたURLにアクセスしてください。

## プロジェクト名について

「きょうゆうさいとー」は、情報やおすすめを仲間内で**共有**するサイトという意味を込めた名前です。
